# 🛒 Sistema de Caixa de Loja em Python

Projeto simples desenvolvido para praticar conceitos fundamentais da linguagem Python, focando na interatividade pelo terminal e lógica de tomada de decisão.

## 📌 Sobre o Projeto
O programa simula o caixa de uma loja. Ele recebe o valor total da compra e a forma de pagamento escolhida pelo cliente, aplicando regras automáticas de desconto e gerando um recibo no final.

### Regras de Negócio:
- **Pagamento via PIX:** 10% de desconto no valor total.
- **Pagamento via Cartão:** 5% de desconto para compras acima de R$ 200,00.
- **Demais opções:** Sem desconto aplicado.
